## ماذا يفعل البرنامج؟ / What does it do?

يأخذ اقرأ مستنداتك:

- ملفات PDF نصية عادية
- ملفات PDF ممسوحة ضوئيًا (صور فقط)
- الكتب الضخمة (100 / 500 / 1000+ صفحة)
- مستندات عربية، إنجليزية، أو مختلطة
- صفحات ممسوحة مباشرة من الماسح الضوئي

ويحوّلها — **محليًا بالكامل على جهازك** — إلى صيغ يقرؤها قارئ الشاشة:

| الصيغة | الوصف |
|---|---|
| **DOCX** | نص حقيقي قابل للتحرير، فقرات RTL صحيحة للعربية، عناوين للتنقل |
| **TXT** | نص عادي نظيف (UTF-8 مع BOM — يعمل مع المفكرة وNVDA فورًا) |
| **HTML** | صفحة دلالية `dir="rtl"` و`lang="ar"` للفقرات العربية |
| **PDF قابل للبحث** | الصفحة الأصلية كما هي + طبقة نص مخفية **قابلة للبحث بالعربية** |
| **تقرير جودة** | صفحات قد تحتاج مراجعة يدوية (لا نَعِد بدقة 100%) |

## العربية أولًا / Arabic-first

- محرك Tesseract محليًا مع بيانات `ara` و`eng` و`ara+eng` (نسختا fast وbest — تُستخدم best للعربية تلقائيًا لأنها أدق للمختلط).
- **إعادة بناء ترتيب القراءة هندسيًا**: كلمات الأسطر العربية تُرتَّب من اليمين لليسار مع إبقاء المقاطع الإنجليزية المضمنة بترتيبها الصحيح — بلا عكس نص ولا إفساد للجمل المختلطة.
- إصلاح تلقائي لملفات PDF العربية "سيئة الصنع" التي تخزن النص بأشكال العرض وبترتيب معكوس.
- DOCX بفقرات `<w:bidi/>` ومقاطع `<w:rtl/>` — يقرأها Word وNVDA قراءة سليمة.

## الضخامة والاستئناف / Large books & resume

- معالجة صفحة-بصفحة عبر طابور محدود الحجم: لا يُحمَّل الكتاب في الذاكرة أبدًا (اختبار حقيقي 500 صفحة: ذروة الذاكرة ~366 MB).
- الحالة تُحفظ ذرّيًا بعد كل صفحة: انقطاع الكهرباء أو الإغلاق أو الانهيار؟ "استئناف من الصفحة 439؟"
- فشل صفحة لا يوقف الكتاب: إعادة محاولة واحدة ثم تسجيلها والمتابعة، مع إمكانية إعادة معالجة الفاشلات لاحقًا.

## الماسح الضوئي / Scanner

اختيار الماسح (WIA)، الدقة (200/300/400/600 — نوصي بـ300)، المسح الصامت أو عبر معالج ويندوز (يدعم المغذاة)، ثم بناء PDF والتحويل — كله دون إنترنت.

## التثبيت / Install

شغّل `Iqra-Setup-1.0.0.exe`. لا تحتاج لتثبيت Python أو Tesseract أو Ghostscript — كل شيء مُضمَّن. اختر مجلد التثبيت، وأيقونة سطح المكتب اختيارية، والمزيل من لوحة التحكم.

## الاختبارات / Tests

84 اختبارًا مؤتمتًا، كلها حقيقية (OCR فعلي على صفحات مولّدة فعلًا)، تشمل:
نص عربي/إنجليزي، مسح عربي/إنجليزي/مختلط، PDF مختلط نص+صور، صفحات تالفة حقيقيًا، إلغاء/استئناف، إيقاف مؤقت، فشل صفحة، DOCX/TXT/HTML/PDF/RTL، الماسح، تسميات الوصول، و**كتاب 500 صفحة بقياس RAM فعلي**.

```powershell
# من مجلد المشروع
.venv\Scripts\python.exe -m pytest tests
```

## سطر الأوامر / CLI

```powershell
IqraCLI.exe convert book.pdf -l ara+eng -p balanced -f docx,txt,html,pdf -o "C:\out"
IqraCLI.exe resume "path\to\project.iqra"
IqraCLI.exe selftest
```
