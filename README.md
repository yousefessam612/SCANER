## ماذا يفعل البرنامج؟ / What does it do?

يأخذ اقرأ ملفات PDF — نصية أو ممسوحة ضوئيًا أو العربية «سيئة الصنع» — ويحوّلها محليًا بالكامل إلى:

| الصيغة | الوصف |
|---|---|
| **DOCX** | نص حقيقي قابل للتحرير، فقرات RTL صحيحة `<w:bidi/>` + `<w:rtl/>`، عناوين وقوائم |
| **TXT** | نص عادي نظيف (UTF-8 مع BOM — يعمل مع المفكرة وNVDA فورًا) |
| **HTML** | صفحة دلالية `dir="rtl"` و`lang="ar"` لكل عنصر بحسب لغته |
| **PDF قابل للبحث** | الصفحة الأصلية كما هي + طبقة نص عربية مخفية **قابلة للبحث والنسخ** |
| **تقرير جودة** | صفحات تحتاج مراجعة يدوية — لا نَعِد بدقة 100% |

## العربية أولًا — كيف تُحل مشكلة «الوورد المضروب»؟

المشكلة الشهيرة «ةغللا بدل اللغة» لها أربعة أسباب، وكلها معالجة حتميًا (بلا أي AI):

1. **أشكال العرض (Presentation Forms)**: ملفات عربية كثيرة تخزّن الحروف بأشكالها U+FB50–U+FEFF → NFKC يفكّها إلى حروف أساس متصلة صحيحة.
2. **التخزين المعكوس**: طبقات نص تخزّن الكلمات معكوسة (Tesseract/Adobe قديمًا) → كشف إحصائي على مستوى السطر (`looks_reversed_arabic`) + إعادة بناء هندسية: عكس قائمة الكلمات مع عكس حروف كل كلمة وإبقاء الجُزر اللاتينية/الرقمية بترتيبها.
3. **ترتيب كلمات OCR**: كلمات Tesseract تخرج بترتيب بصري معكوس → إعادة بناء ترتيب القراءة من إحداثيات x (عكس القائمة العربية مع حماية المقاطع الإنجليزية/الرقمية).
4. **الطبقات التالفة/الآلية**: طبقات نص فاسدة (حروف أجنبية، فيض تشكيل، مخرَج OCR خام مدفون) تُكتشف فتُعالج الصفحة بالصورة عبر OCR بدل الثقة بالطبقة.

كذلك:
- محرك Tesseract محليًا (عبر `tesserocr`) بنموذج best للعربية وfast للإنجليزية.
- **سلّم محاولات OCR مُقيَّم**: block → blur → column → إعادة رسم 400dpi → عتبة Otsu، مع **دمج الأسطر المفقودة** من محاولات أخرى (سطر صغير أسقطته محاولة يُتبنّى من محاولة التقطته).
- DOCX بفقرات `<w:bidi/>` ومحاذاة يمنى وخط عربي (Traditional Arabic افتراضيًا) — يقرأه Word وNVDA قراءة سليمة.

## الاستئناف والضخامة

- معالجة صفحة-بصفحة: الصفحة الوحيدة الحية في الذاكرة أبدًا.
- الحالة تُحفظ ذرّيًا (tmp + `os.replace`) بعد كل صفحة: انقطاع كهرباء؟ «استئناف من الصفحة 439؟» — ولا يُعاد لمس المكتمل أبدًا.
- فشل صفحة لا يوقف الكتاب: يُسجَّل في تقرير الجودة ويُتابع.

## التثبيت والاستخدام / Install & Usage

```bash
pip install -r requirements.txt
# بيانات OCR: ضع ara.traineddata وeng.traineddata في runtime/tessdata/
```

**الواجهة الرسومية** (PySide6 — RTL، متوافقة مع NVDA):

```bash
python -m app          # أو انقر run.bat على ويندوز — يجهز البيئة أول مرة
```

سطر الأوامر:

```bash
# تحويل ملف (DOCX افتراضيًا)
python -m app convert book.pdf -f docx,txt,html,pdf -o المخرجات

# استئناف مشروع غير مكتمل
python -m app resume "book.iqra_project"

# تحويل مجلد كامل / مسح من الماسح (ويندوز)
python -m app batch مجلد_الكتب/
python -m app scan --pages 5

# فحص ذاتي (OCR حقيقي + كل الكُتّاب + بحث عربي في PDF)
python -m app selftest
```

